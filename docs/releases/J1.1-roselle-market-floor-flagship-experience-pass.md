# J1.1 — Roselle Market-Floor Flagship Experience Pass

Status: implementation branch candidate

## Purpose

Raise Roselle from a technically complete invitation into the first Seraya guest experience that is judged against the current Indonesian market floor, while preserving the locked public/personal privacy boundary and existing invitation capabilities.

## Experience contract

- Personal guest recognition belongs to the opening ritual through the existing opaque personal greeting slot; guest identity is not copied into `InvitationViewModel`.
- `Buka undangan` is the deliberate user gesture that starts configured invitation audio on Roselle. The existing floating audio control remains the mute/unmute/retry surface.
- Countdown is visually promoted ahead of the event chapter while save-date, calendar, route, map, arrival note, and livestream actions remain inside the schedule journey.
- Gallery, gift, RSVP, and guestbook stay template-owned and are treated as chapters of one invitation rather than detached application cards.
- Farewell owns the return-to-opening action so the invitation does not regain an application utility layer after its emotional ending.
- 430px, 390px, and 360px are explicit guest-view quality gates.

## Deliberate non-goals

- No database migration or draft schema expansion.
- No guest data added to the public invitation view model.
- No invented couple portrait field.
- No invented standalone wedding-film field. Existing event livestream/video capability remains supported where configured.
- No changes to Aruna or Laras art direction.
- No production deployment as part of this branch pass.
