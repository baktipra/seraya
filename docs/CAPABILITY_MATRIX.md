# Seraya Capability Matrix

This matrix describes capabilities available in the current SRY-033 locked implementation baseline.
A listed route or area is a product boundary, not a promise of a future service level.

| Capability                        | Status                        | Route/Area                                                 | Notes                                                                                                                           |
| --------------------------------- | ----------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Private owner dashboard           | Implemented                   | `/dashboard/*`                                             | Authenticated, owner-scoped project workspace.                                                                                  |
| Project creation and management   | Implemented                   | `/dashboard`, `/dashboard/new`, `/dashboard/[projectId]`   | Owner creates and manages private wedding projects.                                                                             |
| Wedding Readiness Center          | Implemented                   | `/dashboard/[projectId]`                                   | Truthful readiness and conditional project navigation; not a delivery/read analytics dashboard.                                 |
| Invitation editor                 | Implemented                   | `/dashboard/[projectId]/invitation`                        | Explicit save; no autosave contract.                                                                                            |
| Owner preview                     | Implemented                   | `/dashboard/[projectId]/preview`                           | Owner-only, draft-based, private preview.                                                                                       |
| Published invitation snapshots    | Implemented                   | Publication service and `/{slug}`                          | Immutable published content; draft changes require manual republish to reach guests.                                            |
| Payment-gated publishing          | Implemented                   | Billing/publish journey                                    | Verified activation payment is required before manual publish or republish.                                                     |
| Guest Manager                     | Implemented                   | `/dashboard/[projectId]/guests`                            | Owner-private guest records and party-size management.                                                                          |
| Personal guest links              | Implemented                   | Guest Manager and Delivery Center                          | One authorized personal invitation capability per active guest state; raw link is shown only through existing controlled flows. |
| Generic invitation                | Implemented                   | `/{slug}`                                                  | Public, snapshot-only, cacheable/static according to runtime contract; no guest data or response controls.                      |
| Personal invitation               | Implemented                   | `/{slug}/g/{guestToken}`                                   | Token-authorized, private/no-store invitation with authorized personal context.                                                 |
| Personal RSVP                     | Implemented                   | Personal invitation and `/{slug}/g/{guestToken}/rsvp`      | Party-level RSVP; attendee count remains separate from invited party capacity.                                                  |
| Personal Guestbook / Ucapan & Doa | Implemented                   | Personal invitation and `/{slug}/g/{guestToken}/guestbook` | Private-by-design message entry tied to the authorized guest capability.                                                        |
| CSV guest import/export           | Implemented                   | Guest Manager / export route                               | Import is add-only under the existing guest contract; export is owner-private.                                                  |
| Guest WhatsApp contact number     | Implemented                   | Guest Manager                                              | Optional owner-managed E.164 contact; not published in snapshots or public output.                                              |
| Manual WhatsApp handoff           | Implemented                   | Delivery Center                                            | Manual `wa.me`-style handoff only; no automation or tracking.                                                                   |
| Delivery Center                   | Implemented                   | `/dashboard/[projectId]/delivery`                          | Prepares personal links and manual sharing after publication.                                                                   |
| RSVP analytics                    | Implemented                   | `/dashboard/[projectId]/rsvp`                              | Owner-facing truthful RSVP counts; no marketing engagement metrics.                                                             |
| Roselle                           | Implemented                   | Invitation renderer                                        | Romantic warmth direction.                                                                                                      |
| Aruna                             | Implemented                   | Invitation renderer                                        | Modern editorial direction.                                                                                                     |
| Laras                             | Implemented                   | Invitation renderer                                        | Formal evening direction. Laras identity/monogram work is not part of SRY-033.                                                  |
| Multi-event schedule              | Implemented                   | Editor and invitation renderers                            | Up to four published events under the existing schedule contract.                                                               |
| Gallery                           | Implemented                   | Editor, preview, public/personal renderer                  | Optional media subject to existing private/public media authorization.                                                          |
| Amplop Digital                    | Implemented                   | Invitation renderer                                        | Optional published invitation content; no payment processing change implied.                                                    |
| WhatsApp automation               | Not implemented               | —                                                          | Manual handoff is the current boundary.                                                                                         |
| Email invitation sending          | Not implemented               | —                                                          | No owner email delivery workflow is implemented.                                                                                |
| QR check-in                       | Proposed / specification only | —                                                          | Not approved implementation scope.                                                                                              |
| Seating                           | Not implemented               | —                                                          | Not part of the current product.                                                                                                |
| Bulk delivery tracking            | Not implemented               | —                                                          | No send/read/delivery tracking is implemented.                                                                                  |
| Bulk messaging                    | Out of scope                  | —                                                          | Current product intentionally avoids automated bulk delivery.                                                                   |
| Event-specific RSVP               | Out of scope                  | —                                                          | RSVP remains party-level for the invitation as a whole.                                                                         |
| Staff, family, or WO access       | Not implemented               | —                                                          | No multi-role operational workspace is implemented.                                                                             |
| Day-of operations                 | Out of scope                  | —                                                          | Not part of the current Seraya core offer.                                                                                      |
